# s21_decimal Library Implementation

## Реализованный функционал

### Обзор
Разработана комплексная библиотека для точных десятичных арифметических вычислений на языке C, реализующая пользовательский тип decimal для финансовых приложений. Библиотека устраняет ограничения нативных типов с плавающей точкой в сценариях, где недопустимы ошибки округления.

### Основная функциональность

#### Реализация типа Decimal
- Создана пользовательская структура данных `s21_decimal` с 128-битным двоичным представлением
- Реализована обработка знакового бита, 96-битной целочисленной компоненты и управление коэффициентом масштабирования
- Поддерживаемый диапазон чисел: от -79,228,162,514,264,337,593,543,950,335 до +79,228,162,514,264,337,593,543,950,335
- Разработаны эффективные алгоритмы манипуляции битами для десятичных операций

#### Арифметические операции
**Сложение (`s21_add`)**
- Реализовано точное десятичное сложение с правильным выравниванием масштабов
- Добавлено обнаружение переполнения и обработка ошибок
- Включено банковское округление для чисел, превышающих емкость мантиссы

**Вычитание (`s21_sub`)**
- Разработано знаковое вычитание с учетом коэффициента масштабирования
- Обеспечена правильная обработка отрицательных результатов и граничных случаев

**Умножение (`s21_mul`)**
- Создан эффективный алгоритм умножения для 96-битных целых чисел
- Реализована корректировка коэффициента масштабирования и предотвращение переполнения
- Добавлено управление точностью для финансовых расчетов

**Деление (`s21_div`)**
- Построен точный алгоритм деления с обработкой остатка
- Реализовано обнаружение деления на ноль и отчетность об ошибках
- Добавлена нормализация коэффициента масштабирования для точных результатов

#### Операции сравнения
- **Меньше (`s21_is_less`)**: Реализовано знаковое сравнение с учетом масштабирования
- **Меньше или равно (`s21_is_less_or_equal`)**: Комбинированная проверка "меньше" и "равно"
- **Больше (`s21_is_greater`)**: Обратная логика сравнения "меньше"
- **Больше или равно (`s21_is_greater_or_equal`)**: Комплексная оценка "больше или равно"
- **Равно (`s21_is_equal`)**: Побитовое сравнение с нормализацией масштабов
- **Не равно (`s21_is_not_equal`)**: Инверсия проверки равенства

#### Система преобразования типов
**Из целого числа (`s21_from_int_to_decimal`)**
- Эффективное преобразование из стандартных целочисленных типов в десятичное представление
- Обработка знака и нулевое масштабирование для целых значений

**Из числа с плавающей точкой (`s21_from_float_to_decimal`)**
- Точное преобразование чисел с плавающей точкой в десятичный формат
- Реализовано извлечение значащих цифр и округление
- Добавлена обработка ошибок для значений вне диапазона и специальных случаев

**В целое число (`s21_from_decimal_to_int`)**
- Преобразование с отбрасыванием дробной части
- Обнаружение переполнения и отчетность об ошибках
- Сохранение знака при преобразовании

**В число с плавающей точкой (`s21_from_decimal_to_float`)**
- Точное преобразование с сохранением точности в пределах ограничений float
- Правильная обработка коэффициентов масштабирования и значащих цифр

#### Математические функции
**Округление вниз (`s21_floor`)**
- Округление в сторону отрицательной бесконечности
- Правильная обработка отрицательных чисел и дробных частей

**Округление (`s21_round`)**
- Реализация банковского округления
- Округление до ближайшего целого с правилами разрешения ничьих

**Усечение (`s21_truncate`)**
- Отбрасывание дробных цифр, включая конечные нули
- Сохранение целой части десятичного значения

**Смена знака (`s21_negate`)**
- Операция инверсии знака
- Эффективная манипуляция битами для смены знака

### Техническая реализация

#### Система обработки ошибок
- Комплексные коды ошибок: 0 (OK), 1 (переполнение), 2 (антипереполнение), 3 (деление на ноль)
- Последовательная отчетность об ошибках во всех функциях
- Проверка входных данных и граничных условий

#### Оптимизация памяти и производительности
- Эффективные операции на уровне битов с использованием битовой манипуляции
- Минимальный объем памяти с оптимизированными структурами данных
- Быстрые алгоритмы для распространенных десятичных операций

#### Тестирование и обеспечение качества
- Разработан обширный набор модульных тестов с использованием фреймворка Check
- Достигнуто покрытие кода более 80%, проверенное с помощью gcov
- Создан автоматизированный конвейер тестирования с Makefile
- Сгенерированы детализированные HTML-отчеты о покрытии

#### Система сборки
- Комплексный Makefile с несколькими целями:
  - `all`: Полная сборка, включая библиотеку и тесты
  - `clean`: Очистка ресурсов
  - `test`: Выполнение тестов и проверка покрытия
  - `s21_decimal.a`: Компиляция статической библиотеки
  - `gcov_report`: Генерация HTML-отчета о покрытии

### Ключевые особенности

#### Управление точностью
- Поддержка точного десятичного представления без ошибок с плавающей точкой
- Реализована правильная обработка коэффициента масштабирования для дробных значений
- Обеспечено согласованное поведение во всех арифметических операциях

#### Соответствие финансовым расчетам
- Банковское округление для минимального смещения при округлении
- Поддержка больших чисел, необходимых в финансовых приложениях
- Точная десятичная арифметика без потери точности

#### Кросс-платформенная совместимость
- Строгое соответствие стандарту C11
- Совместимость с POSIX.1-2017
- Соблюдение руководства по стилю Google для согласованности кода
