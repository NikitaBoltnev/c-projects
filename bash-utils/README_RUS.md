# Simple Bash Utils

## Реализованный функционал

### Часть 1: Разработка утилиты cat

#### Основная функциональность
- Разработана пользовательская утилита `s21_cat`, воспроизводящая основную функциональность стандартной Unix-команды cat
- Реализована функция отображения содержимого файлов для одного и нескольких файлов
- Добавлена поддержка объединения нескольких файлов и последовательного отображения их содержимого

#### Поддержка опций командной строки
- **-b / --number-nonblank**: Реализована нумерация строк исключительно для непустых строк
- **-e / -E**: Добавлено отображение символов конца строки с маркером `$`, включая совместимое с GNU поведение
- **-n / --number**: Разработана комплексная нумерация всех выходных строк
- **-s / --squeeze-blank**: Создан интеллектуальный алгоритм сжатия нескольких смежных пустых строк
- **-t / -T**: Реализована визуализация символов табуляции как `^I` с правильной совместимостью с GNU

#### Технические детали реализации
- Структурированный код на C в соответствии с руководством по стилю Google и стандартом C11
- Реализованы эффективные операции файлового ввода-вывода с правильной обработкой ошибок
- Разработана модульная архитектура кода с отдельными функциями для каждой опции
- Добавлена комплексная проверка входных данных и отчетность об ошибках
- Создан Makefile с правильными целями сборки и управлением зависимостями

### Часть 2: Базовая реализация утилиты grep

#### Движок сопоставления шаблонов
- Разработана утилита `s21_grep` с фундаментальными возможностями поиска шаблонов
- Реализована поддержка регулярных выражений с использованием стандартных библиотек regex
- Добавлена функциональность обработки файлов для одного и нескольких файлов ввода

#### Поддержка основных флагов
- **-e pattern**: Реализовано явное указание шаблона
- **-i**: Разработана функциональность регистронезависимого сопоставления
- **-v**: Создана система фильтрации с инвертированным сопоставлением
- **-c**: Добавлен подсчет совпадений с агрегацией строк
- **-l**: Реализован вывод только имен файлов для совпадающих файлов
- **-n**: Разработана система нумерации строк для найденных результатов

#### Реализация алгоритмов поиска
- Построены эффективные алгоритмы сопоставления строк с интеграцией regex
- Реализовано чтение файлов и построчная обработка
- Добавлена поддержка нескольких шаблонов и файлов в одном выполнении
- Разработано правильное форматирование вывода в соответствии со стандартами Unix grep

### Часть 3: Расширенные возможности grep (Дополнительно)

#### Реализация расширенных флагов
- **-h**: Разработано подавление имен файлов при многопоточном поиске
- **-s**: Реализована тихая обработка ошибок для недоступных файлов
- **-f file**: Создана функциональность чтения файлов шаблонов
- **-o**: Добавлено извлечение и отображение совпадающих частей

#### Улучшенное управление шаблонами
- Реализована загрузка шаблонов из внешних файлов
- Разработана эффективная система хранения и сопоставления шаблонов
- Добавлена поддержка сложных regex-шаблонов из файловых источников
- Создана оптимизированная выдача для извлеченных сегментов совпадений

### Часть 4: Поддержка комбинаций флагов (Дополнительно)

#### Сложные взаимодействия флагов
- Реализованы все возможные двухфлаговые комбинации (например, `-iv`, `-in`, `-vc`)
- Разработано интеллектуальное управление приоритетом и взаимодействием флагов
- **Комбинация -i -v**: Регистронезависимое инвертированное сопоставление
- **Комбинация -i -n**: Регистронезависимый поиск с номерами строк
- **Комбинация -c -l**: Отчет о количестве с выводом только имен файлов
- **Комбинация -v -n**: Инвертированное сопоставление с нумерацией строк

#### Логика расширенных комбинаций
- Создана унифицированная система обработки флагов, обрабатывающая все перестановки
- Реализован эффективный алгоритм для комбинированного поведения флагов
- Разработано комплексное тестирование для всех сценариев взаимодействия флагов
- Обеспечено согласованное поведение со стандартной утилитой grep
