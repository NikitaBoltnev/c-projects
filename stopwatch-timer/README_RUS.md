Это мой проект по реализации секундомера и таймера в рамках единой программы.

## Интерфейс:
- Присутствуют часы, которые обновляются в реальном времени.
- Из интерфейса можно запустить секундомер или таймер.

## Секундомер:
- Присутствуют часы, которые обновляются в реальном времени.
- Имеет точность до десятых долей секунды.
- Может отсчитывать время до 23 часов, 59 минут и 59 секунд. При достижении этого лимита время сбрасывается до значений 00:00:00:0, и секундомер продолжает свою работу.
- Запускается автоматически после перехода в соответствующий раздел.
- Имеется возможность поставить секундомер на паузу и продолжить отсчёт времени с момента, на котором он была остановлена.
- Есть возможность засекать интервалы (круги). Интерфейс вмещает три поля с интервалами. При записи четвёртого интервала первый интервал стирается, и его место занимает новый. При повторной записи второй интервал стирается, и его место занимает новый, и так далее.
- Есть возможность перезапустить секундомер, сбросив временные значения и интервалы. При этом секундомер начнёт отсчёт заново, без необходимости выхода в главное меню.
- Весь функционал работает как во время работы секундомера, так и в состоянии паузы.
- На каждом этапе работы с секундомером есть возможность вернуться в главное меню (раздел `Интерфейс`).

## Таймер :
- Присутствуют часы, которые обновляются в реальном времени.
- Имеет точность до 1 секунды.
- Позволяет задать время в пределах 23 часов, 59 минут и 59 секунд.
- Для выбора раздела (часы, минуты или секунды) и настройки времени используются стрелки: `вверх, вниз, влево, вправо`.
- Интерфейс настройки цикличен, нет возможности превысить установленные границы.
- Предусмотрена защита от случайного запуска: невозможно запустить таймер, если не выбрано никакого времени.
- Для удобства во время настройки, временное значение, на котором находится пользователь (часы, минуты или секунды), мигает.
- После запуска таймера есть возможность остановить его в любой момент, перезапустить или вернуться на этап настройки времени без необходимости выхода в главное меню.
- Когда таймер доходит до значения 00:00:00, происходит автоматический переход в главное меню (раздел `Интерфейс`). Для уведомления проигрывается мелодия, которая находится в папке `musicForTimer`. Реализовано проигрывание мелодии для Linux.
- На каждом этапе работы с таймером есть возможность вернуться в главное меню (раздел `Интерфейс`).


## Общая информация:
- Программа собирается с помощью Makefile.
- Программу можно запустить через Makefile с целью run.
- Для управления программой используется английская раскладка клавиатуры.
